## 二、技术背景与问题

### 2.1 行业痛点

| 问题 | 具体描述 |
|------|----------|
| **妆效不持久** | 外出或活动后容易脱妆，油性皮肤更为明显 |
| **泛油光** | 皮肤出油后降低透气性，面部产生黏腻感 |
| **妆容暗沉** | 皮脂润湿妆容后容易变得暗沉 |
| **传统成膜剂局限** | 油溶性成膜剂仅抗水，无法解决皮脂分泌导致的脱妆 |
| **多孔粉体局限** | 多孔二氧化硅、多孔PMMA等可吸油但不具固化皮脂功能 |

### 2.2 技术需求

开发一种**同时实现持妆+控油**的化妆品组合物，能够：
- 抗水抗皮脂迁移
- 定向吸收并**絮凝固化皮脂**
- 控油但不干燥
- 轻盈舒适的肤感

## 三、核心创新点

### 创新点1：四元协同持妆控油组合物

| 组分 | 功能定位 |
|------|----------|
| **聚二甲基硅氧烷与多元醇共聚物** | W/O乳化剂，分散粉体，改善厚重黏腻感 |
| **成膜剂（聚甲基硅倍半氧烷+三甲基硅烷氧基硅酸酯）** | 紧密锁粉，抗水抗迁移 |
| **功能性粉体（合成氟金云母+羟基磷灰石+氧化锌）** | 定向吸附并絮凝固化皮脂 |
| **挥发性硅油** | 溶解成膜剂和乳化剂，加快成膜速度 |

### 创新点2：双成膜剂协同增效

- **三甲基硅烷氧基硅酸酯**：疏水性强、抗水耐摩擦，但膜偏硬
- **聚甲基硅倍半氧烷**：疏水性强、膜性柔软
- 两者复配（重量比1:1.5~1:10）：降低膜硬度、降低脆性、提高耐摩擦性

### 创新点3：定向絮凝固化皮脂的功能性粉体

- **合成氟金云母**（≥70%）：提供基底吸附能力
- **羟基磷灰石**（≤20%）：定向吸附皮脂
- **氧化锌**（≤10%）：辅助控油、抗菌
- 特点：吸附皮脂后**将其固化**，而非仅吸收，提高妆容持久性

### 创新点4：聚二甲基硅氧烷与多元醇共聚物乳化体系

- PEG/PPG-18/18、19/19、20/20聚二甲基硅氧烷
- W/O型乳化剂，肤感轻盈水润
- 减少成膜后黏感，减少皮脂分泌后的黏腻感

## 四、聚甘油-3二异硬脂酸酯（PG3-DIIS）在本专利中的角色

### 4.1 权利要求中的定位

> **权利要求5**明确指定："所述乳化剂为**聚甘油-3二异硬脂酸酯**"

PG3-DIIS在本专利化妆品配方中被指定为**乳化剂**成分，用于替代或搭配PEG/PPG聚二甲基硅氧烷类乳化剂。

### 4.2 说明书中的描述

> [0021] "所述乳化剂为双-PEG/PPG-14/14聚二甲基硅氧烷//环五聚二甲基硅氧烷和/或**聚甘油-3二异硬脂酸酯**，**更优选二者的组合**"

### 4.3 PG3-DIIS的功能定位

| 属性 | 说明 |
|------|------|
| **INCI名称** | Polyglyceryl-3 Diisostearate（聚甘油-3二异硬脂酸酯） |
| **功能角色** | **W/O型乳化剂** |
| **用量范围** | 化妆品总量的 **1.5%~3.5%** |
| **配伍乳化剂** | 双-PEG/PPG-14/14聚二甲基硅氧烷//环五聚二甲基硅氧烷 |
| **应用产品** | 粉底液、持妆底妆化妆品 |

### 4.4 PG3-DIIS的作用机理

```
┌─────────────────────────────────────────────────────────┐
│              PG3-DIIS 在持妆控油粉底中的作用              │
├─────────────────────────────────────────────────────────┤
│                                                         │
│  1. 【W/O乳化】形成油包水体系，包裹水相和功能性粉体      │
│                                                         │
│  2. 【肤感调节】相比PEG/PPG类乳化剂，肤感更柔滑轻盈      │
│                                                         │
│  3. 【成膜辅助】帮助成膜剂在皮肤上均匀铺展               │
│                                                         │
│  4. 【粉体分散】辅助分散功能性粉体和着色剂               │
│                                                         │
│  5. 【持妆增效】与双-PEG/PPG-14/14聚二甲基硅氧烷协同     │
│     提高妆容持久性和抗迁移性                             │
│                                                         │
└─────────────────────────────────────────────────────────┘
```

### 4.5 对比实验数据（PG3-DIIS vs PEG/PPG类乳化剂）

专利中设置了**对比应用例4**：将应用例6中的PEG/PPG-18/18、19/19、20/20聚二甲基硅氧烷**全部替换为等量的聚甘油-3二异硬脂酸酯**。

#### 控油效果对比

| 样品 | 油斑直径(mm) | 评价 |
|------|-------------|------|
| 应用例1（PEG/PPG类） | 7.9 | ✅ 优秀 |
| 应用例6（PEG/PPG类） | 8.3 | ✅ 优秀 |
| **对比应用例4（PG3-DIIS替换）** | **15.0** | ❌ 控油显著变差 |

> **结论**：单独使用PG3-DIIS替代PEG/PPG聚二甲基硅氧烷，控油效果明显下降（油斑直径从~8mm增大到15mm）。

#### 感官评估对比（0-5分制）

| 评价维度 | 应用例6（PEG/PPG） | 对比应用例4（PG3-DIIS） |
|----------|-------------------|------------------------|
| 持久性 | 4.8 | 3.3 |
| 铺展性 | 4.6 | 3.2 |
| 柔滑度 | 4.6 | 3.1 |
| 贴肤性 | 4.9 | 3.7 |
| 舒适感 | 4.7 | 2.8 |
| 控油效果 | 4.5 | 2.6 |

> **结论**：PG3-DIIS单独替代PEG/PPG类乳化剂后，各项感官指标均显著下降，尤其是**舒适感（4.7→2.8）**和**控油效果（4.5→2.6）**。

### 4.6 关键启示

| 使用方式 | 效果 | 建议 |
|----------|------|------|
| **PG3-DIIS单独作为主乳化剂** | 控油和肤感均较差 | ❌ 不推荐 |
| **PG3-DIIS + PEG/PPG类乳化剂复配** | 说明书"更优选二者的组合" | ✅ 推荐 |
| **PEG/PPG类乳化剂单独使用** | 控油和肤感均优秀 | ✅ 最优 |

## 七、制备工艺

### 7.1 详细步骤

```
步骤① D相预处理：
  用环五聚二甲基硅氧烷和/或聚二甲基硅氧烷将成膜剂
  （聚甲基硅倍半氧烷+三甲基硅烷氧基硅酸酯）混合搅拌溶解均匀
  → 加入D相余料均质分散均匀，备用

步骤② A1+D相混合：
  将预处理好的D相与A1相原料混合，研磨至细腻备用

步骤③ A3相处理：
  A3相原料混合加热至68-72℃，搅拌溶解均匀备用

步骤④ B3相处理：
  B3相原料混合加热至68-72℃，搅拌溶解均匀备用

步骤⑤ A相混合：
  将A1+D相、A2相、A3相加入乳化锅
  搅拌加热至50-55℃，均质至均匀，保温待用

步骤⑥ B相制备：
  B1相原料加入水相锅，加热至85-90℃
  → 加入预先搅拌分散均匀的B2相，均质3-5min
  → 搅拌保温5-10min至均匀
  → 降温至60℃，加入处理好的B3相搅拌均匀
  → 50-55℃保温待用

步骤⑦ 乳化：
  搅拌状态下，将水相锅中的原料缓慢抽入乳化锅
  → 均质均匀，真空保温搅拌至无泡后降温

步骤⑧ 出料：
  降温至45℃，加入C相原料搅拌均匀
  → 降温40℃，均质4-5min至标准稠度
  → 降温至38℃，报检合格后出料
```

| **控油效果** | 油斑直径~8mm（优秀） | 油斑直径15mm（差） |
| **肤感舒适度** | 4.7分（优秀） | 2.8分（差） |
| **持妆持久性** | 4.8分（优秀） | 3.3分（一般） |
| **粉体分散能力** | 优秀 | 一般 |

### 9.3 配方设计启示

1. **PG3-DIIS可作为W/O乳化剂用于粉底类产品**，但单独使用效果不如PEG/PPG聚二甲基硅氧烷
2. **最佳用法是与PEG/PPG类乳化剂复配**：说明书明确"更优选二者的组合"
3. PG3-DIIS可能在**肤感柔滑度**方面贡献独特价值，但在**粉体分散和控油**方面不如PEG/PPG类乳化剂
4. 对于**高粉体含量**的持妆粉底，建议以PEG/PPG聚二甲基硅氧烷为主乳化剂，PG3-DIIS为辅
