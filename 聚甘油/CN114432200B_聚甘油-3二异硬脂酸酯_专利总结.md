## 二、核心创新点

### 1. 全植物来源环保配方
- 配方中 **70% 以上为植物来源成分**，不使用硅油、硅油乳化剂、香精、酒精、尼泊金酯、矿物油脂
- 属于**零残忍（Cruelty-Free）、素食配方（Vegan）**，符合国际清洁美妆（Clean Beauty）趋势
- 解决传统粉底液化学合成成分及动物成分**降解难、不环保**的问题

### 2. 护肤与彩妆二合一
- 添加植物功效成分替代普通活性物，实现：
  - **保湿修复**：甘油、1,3-丁二醇、氢化磷脂酰胆碱、乳酸
  - **美白祛斑**：抗坏血酸葡糖苷、乳酸、酒石酸
  - **抗氧化**：生育酚醋酸酯、茶叶提取物、对羟基苯乙酮
  - **软化角质**：柠檬酸、葡糖酸
- 避免了活性物的离子性对产品稳定性的负面影响

### 3. 优异的稳定性
- 通过**植物油脂的选择 + 乳化剂搭配 + 植物功效成分**的协同设计
- 产品在 **3000 rpm 条件下离心 30 min 后仍保持良好稳定状态**
- 无浮粉、卡粉、积粉现象，效果持久

### 4. 卓越的肤感体验
- 植物来源油脂（C13-15烷、C15-19烷、角鲨烷、二辛基醚）轻薄易铺展
- 涂抹后为皮肤带来**清爽丝滑**的肤感
- 使用后贴肤细腻，肤感评价优于传统配方

## 三、聚甘油-3 二异硬脂酸酯的核心作用（重点）

### 3.1 功能定位
在该专利配方中，**聚甘油-3 二异硬脂酸酯（Polyglyceryl-3 Diisostearate）** 承担**核心乳化剂**角色，是油相与水相稳定结合的关键组分。

### 3.2 用量范围
| 项目 | 用量（重量百分比）|
|------|------------------|
| 权利要求范围 | **3% ~ 7%** |
| 实施例一（优选）| **5%** |
| 实施例二 | **4.5%** |
| 实施例三 | **5%** |

> 聚甘油-3 二异硬脂酸酯在配方中属于**用量最高的乳化剂之一**，体现了其在体系中的核心地位。

### 3.3 在配方中的协同乳化体系
聚甘油-3 二异硬脂酸酯并非单独作用，而是与其他乳化剂形成**复合乳化体系**：

| 乳化剂 | 用量范围 | 与聚甘油-3 二异硬脂酸酯的协同关系 |
|--------|---------|----------------------------------|
| **聚甘油-3 二异硬脂酸酯** | **3% ~ 7%** | **主乳化剂**，提供超强乳化作用 |
| 聚甘油-6 油酸酯 | 1% ~ 3% | 辅助乳化，调节HLB平衡 |
| PEG-30 二聚羟基硬脂酸酯 | 0.5% ~ 2% | 辅助乳化剂，增强界面稳定性 |
| 聚甘油-3 | 0.1% ~ 0.2% | 辅助乳化，增强保湿性 |
| 甘油山嵛酸酯 | 1% ~ 3% | 辅助乳化兼柔润作用 |

### 3.4 技术贡献
- **替代硅油类乳化剂**：传统粉底液常用硅油乳化剂，本专利以聚甘油-3 二异硬脂酸酯等植物来源乳化剂全面替代，解决了硅油难降解、肤感厚重的问题
- **超强乳化能力**：专利说明书明确指出聚甘油-3 二异硬脂酸酯具有"**超强乳化作用**"
- **提升产品稳定性**：与聚甘油-6 油酸酯、PEG-30 二聚羟基硬脂酸酯搭配，使产品在高速离心条件下仍保持稳定
- **植物来源可降解**：符合清洁美妆的环保理念

### 3.5 制备工艺中的关键步骤
```
步骤a（油相制备）：
先将聚甘油-3 二异硬脂酸酯与氢化聚异丁烯、三羟基硬脂精
按配比称取，保温均质10min，然后再加入其他油相成分搅拌均匀
```
> 聚甘油-3 二异硬脂酸酯在油相制备的**第一步即加入**，并经过均质处理，说明其在油相基质构建中起到**基础骨架**作用。

## 五、制备工艺

### 5.1 工艺流程图
```
步骤a：油相制备
    聚甘油-3 二异硬脂酸酯 + 氢化聚异丁烯 + 三羟基硬脂精
              ↓
        保温均质 10 min
              ↓
    加入 C13-15烷、C15-19烷、双淀粉磷酸酯、聚甘油-6油酸酯、
    二辛基醚、甘油山嵛酸酯、霍霍巴酯、向日葵籽蜡、紫荆树花蜡、
    聚甘油-3、二硬脂二甲铵锂蒙脱石、PEG-30二聚羟基硬脂酸酯、
    生育酚醋酸酯、硅石、色粉（三辊机研磨好）
              ↓
        搅拌均匀 → 油相完成

步骤b：水相制备
    甘油 + 1,3-丁二醇 + 苯氧乙醇 + 乙基己基甘油 + 
    氯化钠 + 水 + 硅酸钠镁锂 + 焦磷酸四钠
              ↓
        充分搅拌溶解 → 水相完成

步骤c：乳化
    油相加热至 85℃ ←——→ 水相加热至 85℃
              ↓
    均质中将水相缓慢加入油相
              ↓
        充分均质混匀

步骤d：冷却
    冷却至室温 + 缓慢搅拌 → 成品
```

### 5.2 工艺要点
- **聚甘油-3 二异硬脂酸酯在油相制备的第一步即加入**，与氢化聚异丁烯、三羟基硬脂精先行均质，构建油相基础骨架
- 乳化温度为 **85℃**
- 采用**水相加入油相**的乳化方式
- 冷却阶段需缓慢搅拌，确保体系稳定
