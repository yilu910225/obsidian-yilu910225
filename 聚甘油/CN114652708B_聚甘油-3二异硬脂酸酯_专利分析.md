## 二、技术背景与创新点

### 2.1 技术问题

| 问题 | 具体描述 |
|------|----------|
| 深部疼痛难以治疗 | 胸腹膜、内脏、肌肉和关节等部位的疼痛定位不精确，传统方法效果差 |
| 辣椒素副作用大 | 高浓度辣椒素（0.1%~8%）易引起皮肤烧灼、刺痛、红肿 |
| 外用药物渗透难 | 痛经等深部疼痛，药物需穿透腹膜和子宫壁，传统贴剂难以到达 |
| 现有贴剂效果不佳 | 长时间贴附引起皮疹、过敏等问题 |

### 2.2 核心创新点

#### 创新点1：低浓度辣椒素协同增效配方
- **辣椒素含量低于0.1%**（优选0.001%~0.015%）
- 通过**"扩散伤害性抑制控制理论"**实现镇痛：皮肤伤害性刺激通过背角神经元汇聚，抑制深部肌肉伤害性感受神经元的异常活动
- 低浓度辣椒素+香兰基丁醚协同激活TRPV1受体，减少副作用的同时增强止痛效果

#### 创新点2：PG3-DIIS / PGPR 油包水乳化体系 ⭐
- **聚甘油-3二异硬脂酸酯 + 聚甘油蓖麻油醇酸酯（PGPR）** 作为专属乳化剂组合
- 形成**油包水（W/O）基质**，有效溶解辣椒素和香兰基丁醚
- 帮助活性成分更好地渗透皮肤，发挥激活TRPV1受体的作用

#### 创新点3：辣椒素与香兰基丁醚的黄金比例
- 辣椒素作用迅速但持续时间短，香兰基丁醚作用温和但持续时间长
- 优选重量比 **1:3000 ~ 1:10000**（辣椒素:香兰基丁醚）
- 两者协同激活TRPV1受体，实现快速+持久的双重镇痛效果

#### 创新点4：水杨酸甲酯降低副作用
- 水杨酸甲酯作为非甾体类抗炎药，发挥消炎作用
- 有效降低辣椒素和香兰基丁醚引起的皮肤红肿副作用

## 三、聚甘油-3二异硬脂酸酯（PG3-DIIS）在本专利中的核心角色

### 3.1 PG3-DIIS 功能定位

| **用量范围** | 基于组合物总重量的 **20%~45%**（与PGPR合计） |

### 3.2 PG3-DIIS 的核心功能

```
┌─────────────────────────────────────────────────────────┐
│              PG3-DIIS + PGPR 乳化体系功能                │
├─────────────────────────────────────────────────────────┤
│ 1. 【溶解载体】有效溶解辣椒素（脂溶性活性成分）          │
│ 2. 【W/O乳化】形成油包水基质，稳定膏状制剂               │
│ 3. 【渗透促进】帮助活性成分穿透皮肤角质层                │
│ 4. 【热稳定性】与PGPR协同，提供良好的热稳定性            │
│ 5. 【无不良气味】不影响产品的使用体验                    │
│ 6. 【安全性】外用安全，风险系数低                        │
└─────────────────────────────────────────────────────────┘
```

### 3.3 专利中关于PG3-DIIS的关键描述

> "聚甘油-3二异硬脂酸酯(POLYGLYCERYL-3 DIISOSTEARATE)，主要在化妆品、护肤品里主要作用是乳化剂，风险系数为1，外用安全。聚甘油蓖麻油醇酸酯(POLYGLYCEROL POLYRICINOLEATE, PGPR)，具有良好的热稳定性，没有不良气味，可以作为乳化剂，用于制备化学组合物。**在本发明中，这两种物质主要是油包水基质，作为乳化剂，有助于辣椒素和香兰基丁醚更好的溶解，发挥激活TRPV1受体的作用。**"

### 3.4 PG3-DIIS 与 PGPR 的协同作用

| PG3-DIIS 特性 | PGPR 特性 | 协同效果 |
|---------------|-----------|----------|
| 低HLB亲油性乳化剂 | 高分子量W/O乳化剂 | 稳定W/O乳液结构 |
| 良好的油脂溶解能力 | 优异的界面稳定能力 | 高效溶解并稳定辣椒素 |
| 外用安全（风险系数1） | 无不良气味 | 产品安全性高、体验好 |
| 热稳定性好 | 热稳定性好 | 加热制备过程稳定 |

## 五、制备工艺

### 5.1 制备步骤

```
步骤1：将水杨酸甲酯与香兰基丁醚进行混合
        ↓
步骤2：加入配置好适宜浓度的辣椒素
        ↓
步骤3：加入聚甘油-3二异硬脂酸酯和聚甘油蓖麻油醇酸酯
        ↓
步骤4：将全部组分进行充分混合，加热到20℃~80℃
        ↓
步骤5：使用磁力搅拌器充分搅拌
        • 搅拌速度：400~1200 r/min
        • 搅拌时间：15~60 min（例如30 min）
        ↓
步骤6：搅拌均匀后，温度下降，液体形态自然形成膏状
        ↓
步骤7：进行等体积分装
```

### 5.2 工艺特点

| 特点 | 说明 |
|------|------|
| **温度温和** | 仅20~80℃，无需高温 |
| **设备简单** | 磁力搅拌器即可 |
| **无需均质** | 自然冷却形成膏状 |
| **一步混合** | 所有组分同时加入，操作简便 |
| **能耗低** | 适合大规模生产 |

## 九、权利要求要点

### 独立权利要求1
一种施用于皮肤表面治疗深部组织疼痛的药物组合物，由以下成分组成：
- 辣椒素：0.001%~0.015%
- 香兰基丁醚：5%~50%
- 水杨酸甲酯
- 辣椒素:香兰基丁醚 = 1:3000 ~ 1:10000

### 权利要求5（PG3-DIIS核心权利要求）
**乳化剂是聚甘油-3二异硬脂酸酯和聚甘油蓖麻油醇酸酯**，含量分别为基于组合物总重量的20%~45%。

### 权利要求14（制备方法）
包含以下步骤：
1. 将水杨酸甲酯与香兰基丁醚混合
2. 加入辣椒素
3. **加入聚甘油-3二异硬脂酸酯和聚甘油蓖麻油醇酸酯**
4. 加热到20℃~80℃
5. 充分搅拌（400~1200 r/min，15~60 min）

### 权利要求15（用途权利要求）
组合物用于制备**治疗痛经的药物**的用途。

### 10.3 配方设计启示

1. **PG3-DIIS + PGPR是辣椒素制剂的理想载体**：两者均为聚甘油酯类，具有良好的生物相容性和脂溶性

3. **W/O体系适合脂溶性药物**：辣椒素在油相中溶解度更高，W/O乳液有助于提高载药量和透皮渗透

5. **无不良气味**：不影响含香兰基丁醚等香料成分的产品体验
